GEOLEX – HƯỚNG DẪN ĐƯA LÊN MẠNG VÀ CÀI TRÊN ĐIỆN THOẠI

BƯỚC 1. Đưa ứng dụng lên mạng (miễn phí, khoảng 2 phút)
  1. Giải nén file geolex-app.zip, được thư mục "geolex-pwa".
  2. Trên máy tính, mở trang: https://app.netlify.com/drop
  3. Đăng nhập (có thể dùng tài khoản Google), rồi kéo thả CẢ THƯ MỤC "geolex-pwa" vào trang.
  4. Netlify cấp cho bạn một đường link dạng https://ten-ngau-nhien.netlify.app
     (có thể đổi tên trong mục Site settings, ví dụ https://geolex.netlify.app nếu tên còn trống).
  Cách khác: GitHub Pages, Vercel, Firebase Hosting… đều được, miễn là chạy bằng https.

BƯỚC 2. Cài lên điện thoại
  Android (Chrome): mở link → bấm nút "Cài app" trên đầu trang, hoặc menu ⋮ → "Cài đặt ứng dụng".
  iPhone/iPad (Safari): mở link → nút Chia sẻ → "Thêm vào MH chính".

Sau khi cài: GeoLex có biểu tượng riêng, mở toàn màn hình, tra cứu được cả khi không có mạng
(video YouTube vẫn cần mạng).

CẬP NHẬT NỘI DUNG
  Khi có bản index.html mới: thay file trong thư mục, mở file sw.js và đổi "geolex-v3" thành
  "geolex-v4" (tăng số), rồi kéo thả lại thư mục lên Netlify. Điện thoại sẽ tự nhận bản mới.

MUỐN CÓ FILE APK CHO ANDROID (tuỳ chọn)
  Sau khi có link https, vào https://www.pwabuilder.com, dán link → Package for stores → Android
  để tạo file APK/AAB (dùng cài trực tiếp hoặc đưa lên Google Play).
